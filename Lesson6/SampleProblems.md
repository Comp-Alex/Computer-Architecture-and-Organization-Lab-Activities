# Lesson 6 Sample Problems

Based on the lab manual topic: keyboard input, text buffers, and interactive game logic.

## Problem 1: Keyboard input echo
Write a program that reads one character from the keyboard and echoes it back to the screen.

### Requirements
- Use an input service for keyboard read.
- Display the entered key immediately.
- Continue until the user presses `ESC`.

## Problem 2: Character count program
Create a program that accepts characters from the keyboard and counts how many characters the user enters before pressing `ENTER`.

### Requirements
- Read input one key at a time.
- Ignore the final newline or carriage return.
- Show the total character count on the screen.

## Problem 3: Simple guessing game
Write a simple number or letter guessing game.

### Requirements
- Display a prompt and ask the user to enter a choice.
- Compare the input to a fixed secret value.
- Show a message such as `CORRECT!` or `TRY AGAIN!`.

## Challenge: Mini text adventure
Build a small interactive menu with several commands, such as `START`, `HELP`, and `EXIT`, using a text buffer and keyboard input.
