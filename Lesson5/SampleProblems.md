# Lesson 5 Sample Problems

Based on the lab manual topic: BIOS video services, cursor positioning, colors, and screen graphics.

## Problem 1: Cursor to the center
Write a program that moves the cursor to the center of the screen and prints a message.

### Requirements
- Use BIOS video service calls.
- Position the cursor using row and column values.
- Display a short text message after moving the cursor.

## Problem 2: Colored heading
Create a program that displays the text `LAB 5` in a colored format.

### Requirements
- Use BIOS video services to set a color attribute.
- Print the message at a chosen row and column.
- Use a background or foreground color to make the text stand out.

## Problem 3: Screen border design
Write a program that draws a simple box or border using ASCII characters and cursor positioning.

### Requirements
- Use repeated row and column movement.
- Use at least two different symbols such as `+`, `-`, and `|`.
- Keep the border aligned to the screen edges.

## Challenge: Mini screen graphic
Design a simple graphic using pixel-like characters, color changes, and cursor movement to represent a small object, icon, or title banner.
