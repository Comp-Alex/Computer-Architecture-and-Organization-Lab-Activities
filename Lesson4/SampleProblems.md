# Lesson 4 Sample Problems

Based on the lab manual topic: DOS string output and multi-line text displays.

## Problem 1: Display a greeting message
Write an assembly program that prints the string `WELCOME TO COMPUTER ORGANIZATION LAB` using a DOS string-output service.

### Requirements
- Use a string variable stored in memory.
- Display the message on the screen.
- Terminate the program after the output is complete.

## Problem 2: Three-line output
Create a program that prints three lines of text:

```text
COMPUTER ARCHITECTURE
AND
ORGANIZATION
```

### Requirements
- Use a DOS string output routine.
- Place each line as a separate string.
- Maintain readable spacing between each line.

## Problem 3: Centered title
Write a program that displays a title message using a series of text strings and line breaks.

### Requirements
- Use at least two text strings.
- Insert a blank line between sections.
- Keep the display organized and easy to read in DOS mode.

## Challenge: Lab message banner
Design a program that prints a lab banner with sections such as `COURSE`, `TOPIC`, and `GROUP` using separate strings and repeated output calls.
