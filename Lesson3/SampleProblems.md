# Lesson 3 Sample Problems

Based on the lab manual topic: character generation, loops, and formatted output.

## Problem 1: Reverse letter pair
Write a program that prints pairs of letters in descending order using one register for the lowercase character and another for the uppercase character.

### Example output
```text
zA
yB
xC
...
aZ
```

### Requirements
- Use a loop counter.
- Decrement the lowercase value while incrementing the uppercase value.
- Print 26 pairs in total.

## Problem 2: Countdown display
Create a program that shows the numbers `9` down to `1` on separate lines.

### Requirements
- Use a loop.
- Print the value of the loop counter for each iteration.
- End the program after the final value is shown.

## Problem 3: Character table
Write a program that prints the ASCII characters from `A` to `Z` and then from `a` to `z` in a neat sequence.

### Requirements
- Format the output in rows.
- Use a loop to generate each character.
- Add a space between characters for readability.

## Challenge: Custom pattern
Generate a pattern such as `A1`, `B2`, `C3`, ..., `Z26` using nested loops or repeated register manipulation.
