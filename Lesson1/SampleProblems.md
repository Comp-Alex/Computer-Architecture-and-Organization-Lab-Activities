# Lesson 1 Sample Problems

Based on the lab manual topic: TASM editor environment and DOS assembly setup.

## Problem 1: TASM setup check
Write a short note explaining the steps to start the TASM editor, create a new assembly file, save it with a `.asm` extension, and assemble it using DOS commands.

### Requirements
- Mention the purpose of the editor and the source file.
- State how to save the program and what file extension is used.
- List the basic compile step used to test a simple assembly program.

## Problem 2: Simple DOS assembly template
Create a minimal assembly source file that:
- sets up the data segment,
- defines `main`,
- ends the program with a DOS exit call,
- and includes a comment explaining each section.

### Output
A clean, working skeleton program that can be used as a starting point for later exercises.

## Problem 3: File naming and workflow
Explain the workflow used in the lab for creating an Assembly program:
1. open the editor,
2. type the code,
3. save the file,
4. assemble it,
5. run the executable.

### Deliverable
A short workflow checklist suitable for a student lab notebook.
